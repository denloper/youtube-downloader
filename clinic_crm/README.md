# CRM клиники «Семейный доктор»

Полноценная CRM для клиники: запись, очередь, электронная медкарта, лаборатория, назначения, касса, чат, склад, задачи и аналитика.

Интерфейс в палитре существующего сайта [Семейный доктор ИИ](http://201.24.114.71/) — шалфейный зелёный, рабочие столы для главного врача, регистратуры, врача, медсестры и кассы.

## Запуск

```bash
cd clinic_crm
python3 -m pip install -r requirements.txt
python3 app.py
```

Откройте http://127.0.0.1:5050

Полный пересев: `CLINIC_RESEED=1 python3 app.py`

## Модули

1. **Дашборд** — KPI дня, расписание, графики визитов и выручки, задачи, пациенты на контроле, склад ниже минимума.
2. **Расписание** — неделя клиники, слоты 08:00–19:00, запись кликом по ячейке, контроль пересечений у врача.
3. **Очередь** — статусы: записан → подтверждён → ожидает → на приёме → завершён / не явился.
4. **Пациенты** — картотека, поиск, медкарта (аллергии, хронические, группа крови), вкладки ЭМК / анализы / назначения / счета / чат.
5. **Приёмы / ЭМК** — протокол жалобы–анамнез–осмотр–диагноз МКБ-10–рекомендации.
6. **Лаборатория** — заказы, статусы, результаты с отклонениями от нормы.
7. **Назначения** — препараты, схема, курс.
8. **Касса** — счета из прайса, оплата, открытая задолженность.
9. **Чат** — переписка клиника ↔ пациент, непрочитанные.
10. **Склад** — остатки и минимум, пополнение.
11. **Задачи** — поручения персоналу.
12. **Отчёты** — нагрузка врачей, услуги, касса, воронка статусов.
13. **Структура CRM** — схема ролей, модулей и пути пациента.
14. **Настройки** — клиника, прайс, персонал, кабинеты.

## Путь пациента

Обращение → запись в слот → явка в очередь → приём и ЭМК → анализы и назначения → касса → напоминание / повторный визит.

## Данные

SQLite. Основные сущности: пользователи, пациенты, кабинеты, услуги, приёмы, визиты, назначения, лаб.заказы, счета, сообщения, склад, задачи.

Это отдельное рабочее место клиники. Пациентское приложение на `201.24.114.71` можно связать позже через общий backend / Supabase: карточки, чат и записи уже совпадают по смыслу с текущим `doctor.html`.
